# GTM World Model - Agent Simulation Service

LLM-agent market simulation: a panel of AI consumers (personas, budgets, memory)
making real purchase/churn/recommend decisions via Gemini inference. Backend for
https://gtm-world-model.pages.dev - method: Generative Agents (2023), EconAgent
(ACL 2024), MarketFish (2026, MIT).
